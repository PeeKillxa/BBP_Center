# BBP Center - Project Requirements & Specifications

เอกสารฉบับนี้รวบรวมข้อกำหนด ขอบเขต และกติกาการทำงานของเว็บไซต์ร้าน "BBP Center" สำหรับใช้เป็นแนวทางในการออกแบบ พัฒนา และส่งต่อให้ระบบหรือ AI ตัวอื่นเขียนโค้ด

---

## 1. ข้อมูลทั่วไปและแบรนด์ (Brand & Visual Identity)

- **ชื่อร้าน:** BBP Center
- **รูปแบบร้าน:** ร้านผู้ขายรายเดียว (ไม่ใช่ Marketplace หรือตลาดกลาง)
- **สินค้าและบริการ:** 
  - ขายไอดีเกม Roblox (แยกตามหมวดหมู่แมพ)
  - บริการรับฟาร์มเกม Roblox (เริ่มต้นด้วยแมพ Anime Adventures)
- **สไตล์การออกแบบ:** 
  - Minimal + Anime/Fantasy ทันสมัย อ่านง่าย ไม่รก
  - โทนสีอิงจากโลโก้: ดำอมกรมท่า, ฟ้าไซแอน และขาว
  - รองรับ Dark Theme / Light Theme / System Theme
- **แอนิเมชันและลูกเล่น:** มีแอนิเมชันเคลื่อนไหวและลูกเล่นเยอะ (Hero มีแสงไล่สี, การ์ดยกตัวเมื่อ hover, เปลี่ยนหน้าลื่นไหล) แต่ต้องลดความหนักบนมือถือและรองรับการปิดแอนิเมชัน (prefers-reduced-motion)

---

## 2. โครงสร้างเว็บไซต์และเส้นทางผู้ใช้งาน (Sitemap & User Flow)

- **การเข้าสู่ระบบ:** ดูรายการสินค้าและบริการได้โดยไม่ต้องเข้าสู่ระบบ แต่ **ต้องสมัครและเข้าสู่ระบบก่อน** จึงจะสามารถ เติมเงิน, ซื้อไอดี, จองไอดี หรือสั่งซื้อบริการฟาร์มได้
- **ช่องทางเข้าสู่ระบบ/สมัครสมาชิก (ต้นแบบ):** รองรับอีเมลกับรหัสผ่าน, Google, และ Discord

---

## 3. ระบบกระเป๋าเงินและการเติมเงิน (Wallet & Top-up)

- **สกุลเงิน:** ใช้หน่วยเงินบาท (THB)
- **ช่องทางการเติมเงิน:**
  1. **โอนธนาคาร / QR Code:** แสดง QR, อัปโหลดสลิป, ตรวจสอบผ่าน API (ระบบจำลองในต้นแบบ) และเพิ่มยอดเงินเมื่อสำเร็จ
  2. **อั่งเปา TrueMoney:** ช่องวางลิงก์ซองอั่งเปา ตรวจสอบผ่านระบบจำลอง
- **ความปลอดภัย (ระบบจริง):** การตรวจสอบสลิปและซองอั่งเปาต้องทำฝั่งเซิร์ฟเวอร์ ห้ามเชื่อถือผลจากเบราว์เซอร์ และต้องมีระบบป้องกันการกดรับซองหรือสลิปซ้ำ (Idempotency)

---

## 4. ระบบร้านค้าและสินค้าไอดีเกม (Roblox Account Store)

- **หมวดหมู่เริ่มต้น:** 
  - Anime Adventures
  - Anime Vanguards
- **ข้อมูลสินค้าแต่ละรายการ:** 
  - รูปภาพหลายรูป (แกลเลอรี)
  - ชื่อไอดี / หมวดแมพ / ราคา (บาท) / เซิร์ฟเวอร์ (ถ้ามี)
  - คุณสมบัติเด่น (แรงก์, เลเวล, สกิน ฯลฯ)
  - เงื่อนไขการโอนบัญชี และข้อมูลรับประกัน
  - สถานะสินค้า: **พร้อมขาย / จอง / ขายแล้ว**
- **สต็อก:** สินค้าไอดีแต่ละรายการมีชิ้นเดียว ห้ามซื้อซ้ำหลายคน สินค้าที่ถูกจองหรือขายแล้วต้องปิดการซื้อโดยบุคคลอื่นทันที

---

## 5. ระบบการจองไอดี (Reservation System)

- **เงื่อนไขการจอง:**
  - สมาชิกชำระเงินจอง **50% ของราคาไอดี** จากยอดเงินใน Wallet (ล็อกราคาสินค้า ณ เวลานจอง)
  - ระยะเวลาจอง: **12 ชั่วโมง** + ช่วงผ่อนผันอัตโนมัติอีก **2 ชั่วโมง** (รวมเป็น 14 ชั่วโมง)
  - **กรณีจ่ายครบ:** หักยอดส่วนที่เหลือ → เปลี่ยนสถานะเป็นขายแล้ว → เปิดเผยข้อมูลส่งมอบ
  - **กรณีหมดเวลา (เกิน 14 ชั่วโมง):** **ริบเงินจอง 100%** (ไม่คืนเข้า Wallet และไม่นำมาเป็นส่วนลดการซื้อครั้งใหม่), สินค้ากลับมาสถานะพร้อมขาย
  - **Cooldown (ระยะเวลารอคอย):** สมาชิกเดิมที่จองแล้วปล่อยหมดเวลา จะ **ไม่สามารถจองไอดีเดิมซ้ำได้เป็นเวลา 6 ชั่วโมง** นับจากหมดสิทธิ์ (แต่ยังสามารถซื้อไอดีเดิมแบบจ่ายเต็มจำนวนได้ทันที หากสินค้านั้นยังพร้อมขายอยู่)
- **UI/UX:** ต้องมี Checkbox ยอมรับเงื่อนไขการริบเงินจองก่อนยืนยันการจอง และแสดง Countdown ชัดเจน

## 6. ระบบบริการรับฟาร์ม (Farming Service - Anime Adventures)

- **การคิดราคาเรทเพชร Anime Adventures:**
  - แพ็กเกจหลัก:
    - 10,000 เพชร = 20 บาท
    - 20,000 เพชร = 40 บาท
    - 30,000 เพชร = 60 บาท
    - 50,000 เพชร = 100 บาท
    - 100,000 เพชร = 160 บาท
    - 120,000 เพชร = 180 บาท
  - ช่องกำหนดจำนวนเอง: ขั้นต่ำ 10,000 เพชร และเพิ่มทีละ 10,000 เพชร (ใช้สูตรคำนวณตามช่วงเรทและปัดเศษลงตัว)
- **สูตรคำนวณเวลาฟาร์ม (เฉพาะแมพ Anime Adventures):**
  - อัตรา: 18 เพชร / 2 นาที (รวมเวลา Rejoin)
  - จำนวนรอบ = `ceil(จำนวนเพชรที่สั่ง / 18)`
  - เวลาประมาณ (วินาที) = `จำนวนรอบ × 120`
  - แสดงผลลัพธ์เป็น วัน, ชั่วโมง, นาที (ระบุชัดเจนว่าเป็นเวลาประมาณ ไม่รวมคิวและเวลารอยืนยัน)

---

## 7. ขั้นตอนการเข้าถึงไอดีและสแตนด์บาย (Standby & Farm Verification Flow)

เมื่อลูกค้าสั่งซื้อบริการฟาร์มและชำระเงินแล้ว มีขั้นตอนการประสานงานดังนี้:
1. **กรอกข้อมูล:** ลูกค้ากรอก Username และ Password ของ Roblox
2. **เรียกลูกค้าสแตนด์บาย:** แอดมินกดปุ่มในระบบเพื่อเรียกลูกค้า (มีเวลา 5 นาทีให้ลูกค้ากด "พร้อมแล้ว" อยู่หน้าเว็บ)
3. **ยืนยันการเข้าสู่ระบบ (2FA / Verification):** 
   - แอดมินเลือกวิธีขอรหัสยืนยัน (เช่น กรอกรหัสผ่านช่องทางที่ร้านกำหนด หรือกดอนุมัติในแอป Roblox)
   - เริ่มนับเวลา 5 นาทีสำหรับช่วงเวลานี้
4. **ตรวจสอบผลการเข้าใช้งาน:** แอดมินเป็นผู้กดยืนยันผล "เข้าใช้งานสำเร็จ" ด้วยตนเอง (ระบบไม่อัตโนมัติ 100% เพื่อความปลอดภัย)
5. **เริ่มฟาร์ม:** เมื่อเข้าสู่ระบบสำเร็จ สถานะเปลี่ยนเป็นกำลังดำเนินการและแสดงไทม์ไลน์ติดตามงาน
