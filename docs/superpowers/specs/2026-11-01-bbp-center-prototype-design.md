# BBP Center Prototype — Design Spec

วันที่: 2026-11-01 · สถานะ: รอเจ้าของร้านตรวจ

## 1. เป้าหมาย

ต้นแบบหน้าร้านและบัญชีลูกค้าของ BBP Center ที่กดใช้งานได้จริงในเบราว์เซอร์ ใช้ข้อมูลจำลองทั้งหมด และจัดโครงสร้างให้ Codex พัฒนาระบบจริงต่อได้ โดยแยกส่วน mock ออกจากส่วนที่ต้องย้ายไปฝั่งเซิร์ฟเวอร์

ข้อห้ามที่ใช้ทั้งโปรเจกต์:
- ไม่เชื่อม KBank, TrueMoney หรือระบบเงินจริงใด ๆ ไม่เรียก endpoint ภายนอก
- ไม่มี credentials, API key หรือข้อมูลบัญชี Roblox จริงในโค้ด ข้อมูลจำลอง หรือ log
- ไม่บันทึกรหัสผ่านหรือรหัสยืนยันใน localStorage, URL, analytics, console หรือ log

## 2. แหล่งข้อกำหนดและลำดับความสำคัญ

1. คำสั่งล่าสุดของเจ้าของในแชต (เพดาน 250k ฯลฯ ดูหัวข้อ 9)
2. `docs/Markdown.md`
3. Skills local-only ใน `.claude/skills/bbp-*` (ถ้ามีใน workspace; ไม่ใช่ dependency ของ fresh clone)

ค่าใน Prompt_.txt ที่ถูกแทนแล้ว: 20k=38, 30k=54, 50k=85, 15k=29, 40k=69.50, ขั้นทีละ 1,000 เพชร และกฎ 1.60 บาทต่อ 1,000 เพชรเกิน 100k

## 3. สถาปัตยกรรม

React 19 + TypeScript + Vite + Tailwind CSS 4 + Motion for React + Lucide + React Router ที่ `app/`

| ชั้น | ไฟล์ | หน้าที่ | ระบบจริง |
| --- | --- | --- | --- |
| Config | `src/config/farming.ts`, `src/config/rules.ts` | ราคา อัตรา เพดาน เวลา ช่องทางติดต่อ | โหลดจาก backend |
| Domain | `src/domain/engine.ts`, `farming.ts`, `types.ts` | ฟังก์ชันบริสุทธิ์: ซื้อ จอง เติมเงิน ฟาร์ม สแตนด์บาย sweep เวลา | ย้ายไปเซิร์ฟเวอร์ ใช้ DB transaction |
| Mock | `src/mock/seed.ts`, `delivery.ts` | ข้อมูลตัวอย่างทุกสถานะ ข้อมูลส่งมอบปลอม | ลบทิ้ง |
| Store | `src/store/store.ts`, `theme.ts` | เก็บ state สาธิตใน localStorage, นาฬิกาทดสอบ | แทนด้วย API client |
| UI | `src/components/*`, `src/pages/*` | หน้าจอ | ใช้ต่อได้ |

เงินทุกจุดเป็นจำนวนเต็มหน่วยสตางค์ (`Satang`) แสดงผลแบบ `฿1,290.00` ทุกที่

## 5. กฎธุรกิจ

### 5.1 สินค้าไอดีและการซื้อ
- หนึ่งรายการ = หนึ่งบัญชี สต็อก 1 ชิ้น สถานะ พร้อมขาย / จอง / ขายแล้ว
- ขั้นตอน: สรุป → คูปอง (ถ้ามี) → ยืนยันหักยอด → สำเร็จ ก่อนหักยอดตรวจสถานะและราคาซ้ำ ถ้าราคาเปลี่ยนให้ปฏิเสธ
- ยอดไม่พอ: แสดงยอดที่ขาดจริง และปุ่มเติมเงินที่พากลับมาทำรายการต่อ
- หักเงิน สร้างคำสั่งซื้อ และเปลี่ยนสถานะสินค้าในคำสั่งเดียว ใช้ idempotency key ต่อการเปิดหน้ายืนยันหนึ่งครั้ง กดซ้ำไม่หักซ้ำ
- ข้อมูลส่งมอบเป็นค่าปลอมที่สร้างจากเลขคำสั่งซื้อ ไม่บันทึกถาวร แสดงเฉพาะหน้าคำสั่งซื้อของเจ้าของ ซ่อนไว้ก่อน มีปุ่มเปิดดูและคัดลอก ผู้อื่นเห็นเป็น "ไม่พบ"

### 5.2 กระเป๋าเงินและเติมเงิน
- หน่วยเงินบาท ยอดคงเหลือ = ผลรวม ledger ของผู้ใช้
- โอน/QR: ระบุจำนวน, QR ลายตกแต่งที่สแกนจ่ายไม่ได้, แนบสลิป (PNG/JPG/WEBP ≤ 5 MB) พร้อมพรีวิว
- อั่งเปา: วางลิงก์รูปแบบ `https://gift.truemoney.com/campaign/?v=...` ยอดจำลองคงที่ ฿100.00
- ผลจำลอง: สลิป = สำเร็จ / ยอดไม่ตรง / สลิปซ้ำ / ผู้รับไม่ตรง / ตรวจสอบไม่ได้ · อั่งเปา = สำเร็จ / ลิงก์ไม่ถูกต้อง / ใช้แล้ว / หมดอายุ / ผู้ให้บริการไม่พร้อม · สถานะ "กำลังตรวจ" ระหว่างรอ
- เพิ่มยอดเฉพาะผลสำเร็จ ครั้งเดียวต่อรายการ และครั้งเดียวต่อแหล่งที่มา (สลิป/ลิงก์เดิมกลายเป็น "สลิปซ้ำ"/"ใช้แล้ว")
- สถานะเติมเงินเก็บแยกจาก ledger และจากคำสั่งซื้อ

### 5.3 การจอง (Markdown §5)
- หักเงินจอง 50% ของราคา ล็อกราคา ณ เวลาจอง ต้องติ๊ก checkbox ยอมรับการริบเงินจอง (ไม่ติ๊กไว้ก่อน) ซึ่งแสดงยอดที่จะถูกริบและเวลาสิ้นสุด
- ล็อก 12 ชั่วโมง + ผ่อนผันอัตโนมัติ 2 ชั่วโมง สินค้าปิดการซื้อตลอด 14 ชั่วโมง
- ชำระยอดคงเหลือ = ราคาที่ล็อก − เงินจอง สำเร็จแล้วเปลี่ยนเป็นขายแล้วและเปิดข้อมูลส่งมอบ
- ครบ 14 ชั่วโมงยังไม่ชำระ: ริบเงินจอง ไม่คืนเข้า wallet สินค้ากลับมาพร้อมขาย บันทึก ledger รายการริบ (ยอด 0 เพราะหักไปตอนจองแล้ว) แยกจากการซื้อใหม่ ทำครั้งเดียวแม้ sweep ซ้ำ
- Cooldown 6 ชั่วโมงนับจากหมดสิทธิ์ เฉพาะผู้จองเดิม + ไอดีเดิม ระหว่างนั้นซื้อเต็มจำนวนได้ถ้าพร้อมขาย เงินที่ริบไม่นำมาหัก
- UI: ราคาที่ล็อก เงินจองที่จ่ายแล้ว ยอดที่ต้องจ่าย เวลาครบ 12 ชม. เวลาสิ้นสุดผ่อนผัน countdown ป้ายสถานะ และเวลาที่จองซ้ำได้
- ใช้คูปองกับการจองไม่ได้

### 5.4 บริการฟาร์ม
แยกตามแมพและชนิดบริการ (ฟาร์มเพชร / หาตัวลับ / ฟาร์มเลเวล) ทุกค่าอยู่ใน config

**ฟาร์มเพชร Anime Adventures** (ป้าย "ราคาเสนอสำหรับต้นแบบ · รอร้านยืนยัน")

| เพชร | ราคา | ที่มา |
| ---: | ---: | --- |
| 10,000 | 20 | Markdown |
| 20,000 | 40 | Markdown |
| 30,000 | 60 | Markdown |
| 50,000 | 100 | Markdown |
| 100,000 | 160 | Markdown |
| 120,000 | 180 | Markdown |
| 250,000 | 310 | เจ้าของให้ผมกำหนด (1 บาท/1,000 เพชร ต่อจากช่วง 100k–120k) |

- ระหว่างจุดราคาใช้ linear interpolation ในหน่วยสตางค์ ถ้าได้เศษบาทให้ปฏิเสธ (Markdown ไม่ได้กำหนดทิศทางปัด) — ตารางนี้ได้บาทเต็มทุกขั้น
- กำหนดเอง: ขั้นต่ำ 10,000 · เพิ่มทีละ 10,000 · สูงสุด 250,000 มีช่องตัวเลข ปุ่มเพิ่มลด ตัวเลือกด่วน ปฏิเสธค่าว่าง ไม่ใช่ตัวเลข ติดลบ ทศนิยม ต่ำกว่าขั้นต่ำ เกินเพดาน และไม่ตรงขั้น
- การ์ดแพ็กเกจหลัก: 10k / 20k / 50k / 100k / 250k
- เวลา: รอบ = ceil(เพชร / 18), วินาที = รอบ × 120 แสดง วัน ชั่วโมง นาที ติดป้ายว่าเป็นเวลาประมาณ แยกจากเวลารอคิว ไม่ใช่เวลารับประกัน ใช้เฉพาะบริการนี้
- หาตัวลับ / ฟาร์มเลเวล ทุกแมพ: แสดง "รอร้านกำหนดรายละเอียด" ปุ่มสั่งปิดพร้อมเหตุผล
- ช่อง Roblox username/password แสดงหลังชำระแล้ว (Markdown §7) ต้นแบบบังคับชื่อขึ้นต้น `demo_` รหัสผ่านตรวจแค่ไม่ว่างแล้วทิ้ง เก็บเฉพาะชื่อที่ปิดบางส่วน
- ความคืบหน้าแสดงเมื่อร้านรายงานค่าที่วัดได้เท่านั้น ไม่เพิ่มตามเวลา

### 5.5 สแตนด์บายและการเข้าใช้งาน (Markdown §7)
สถานะเข้าใช้งาน: รอเรียกลูกค้า → เรียกสแตนด์บาย → ลูกค้าพร้อม → กำลังเข้าสู่ระบบ → รอรหัสยืนยัน หรือ รออนุมัติใน Roblox → กำลังตรวจผล → เข้าใช้งานสำเร็จ · และ รอนัดใหม่

สถานะงาน: รอรายละเอียด / รอคิว / กำลังดำเนินการ / รอลูกค้าตอบกลับ / เสร็จสิ้น / ยกเลิก

- แอดมินกดเรียกสแตนด์บาย เริ่มนับ 5 นาที ลูกค้าได้แจ้งเตือนและปุ่ม "พร้อมแล้ว" นับว่าตอบรับเมื่อกดปุ่มเท่านั้น
- แอดมินเลือกวิธียืนยันเอง แต่ละคำขอได้ id ใหม่และเวลา 5 นาทีใหม่ (แยกจากเวลาสแตนด์บาย) คำขอใหม่ทำให้คำขอเดิมใช้ไม่ได้
- รูปแบบรหัสอยู่ใน config ไม่กำหนดจำนวนหลัก แจ้งว่ารหัสจริงอาจหมดอายุก่อนเวลาบนเว็บ
- ส่งรหัสหรือกด "ยืนยันแล้ว" = กำลังตรวจผล ไม่ใช่สำเร็จ แอดมินกด "เข้าใช้งานสำเร็จ" เอง แล้วจึงเริ่มฟาร์มได้
- หมดเวลาขั้นใดก็ตาม → รอนัดใหม่ ไม่เก็บเงินเพิ่ม ไม่ริบค่าฟาร์ม
- Timeline บันทึกเฉพาะเหตุการณ์และเวลา ไม่มีรหัสผ่านหรือรหัสยืนยัน
- หน้า `/owner/farm`: รายการงาน รายละเอียดแพ็กเกจ สถานะการตอบรับ ปุ่มเรียกสแตนด์บาย / เริ่มเข้าสู่ระบบ / ขอรหัส / ขออนุมัติ / เข้าใช้งานสำเร็จ / ลองใหม่ (ส่งคำขอซ้ำ) / นัดใหม่ / เริ่มฟาร์ม / อัปเดตงาน / รอลูกค้าตอบกลับ / เสร็จสิ้น ปุ่มที่ใช้ไม่ได้แสดงเหตุผล

### 5.6 ระบบเสริม
- คูปองตัวอย่าง: `DEMO10` (ไอดี ลด 10% สูงสุด ฿100 ขั้นต่ำ ฿300), `FARM5` (ฟาร์ม ลด ฿5), `OLD50` (หมดอายุ) แสดงสถานะ ใช้ได้ / หมดอายุ / ไม่เข้าเงื่อนไข
- รีวิวได้เฉพาะเจ้าของคำสั่งซื้อสำเร็จ หนึ่งรีวิวต่อคำสั่งซื้อ รีวิวหน้าแรกติดป้าย "ข้อมูลตัวอย่าง"
- แจ้งเตือน: ผลเติมเงิน ซื้อสำเร็จ ใกล้ครบ 12 ชม. (1 ชม. ก่อน) เข้าช่วงผ่อนผัน หมดเวลาจอง และอัปเดตงานฟาร์ม
- ปุ่ม LINE / Discord ปิดใช้พร้อมข้อความ "รอร้านกำหนดช่องทาง" ไม่สร้างลิงก์ปลอม
- ไม่มียอดขาย จำนวนลูกค้า หรือคำรับรองที่ดูเหมือนจริง ไม่อ้างเป็นร้านทางการของ Roblox

## 6. สมาชิก
- อีเมล + รหัสผ่าน มี validation, loading, error · Google / Discord ระบุ "โหมดสาธิต" และเข้าเป็นผู้ใช้ตัวอย่าง A ไม่แสร้งว่าเชื่อม OAuth
- ลืมรหัสผ่าน จำลองการส่งลิงก์ ข้อความเดียวกันไม่ว่ามีบัญชีหรือไม่
- รหัสผ่านไม่ถูกบันทึกที่ใดเลย

## 7. ดีไซน์
- โทน Minimal + Anime/Fantasy · Dark: `#070B18` / `#101A30` / `#2563EB` / `#22D3EE` / `#F5F9FF` · Light: ขาวอมฟ้า ตัวอักษรกรมท่า ปรับสีให้คอนทราสต์ข้อความ ≥ 4.5:1
- ธีม Dark / Light / System จดจำใน localStorage (`bbp-theme`) และใช้ก่อน render เพื่อไม่ให้กระพริบ
- ฟอนต์ Noto Sans Thai · โลโก้ `public/brand/bbp-center-logo.png` คัดลอกจากไฟล์เจ้าของ ไม่แก้สัดส่วน · ภาพสินค้าเป็น placeholder ที่สร้างด้วยโค้ด (สิทธิ์ภาพจริงไม่ทราบ) กล่องอัตราส่วนคงที่
- แอนิเมชัน: Hero แสงไล่สี + อนุภาค (ปิดบนมือถือ), การ์ดยกตัวเฉพาะอุปกรณ์มี hover, ปุ่มย่อตอนกด, เปลี่ยนหน้า/modal ลื่น, skeleton, success animation · เคารพ `prefers-reduced-motion` · ไม่มีเสียง

## 10. รอเจ้าของร้านตัดสินใจ
- ยืนยันราคาฟาร์มทั้งตาราง และเพดานต่อออเดอร์จริง

- ข้อความเงื่อนไขการโอน การรับประกัน และเงื่อนไขการใช้งาน
- ลิงก์ LINE / Discord, บัญชีรับเงิน, ภาพสินค้าจริง
- การปัดเศษเงินจอง 50% หากราคาในอนาคตมีเศษสตางค์
