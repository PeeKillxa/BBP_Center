# เพิ่มสินค้าและสต็อก

บัญชีแอดมินเพิ่มหมวดหมู่และสินค้าได้จากหน้าแรก `/` และหน้าสินค้า `/maps` โดยไม่ต้องเข้าหน้าบัญชี ปุ่มไม่แสดงให้ลูกค้าทั่วไป และ API ตรวจสิทธิ์แอดมินเสมอ

1. กด **เพิ่มหมวดหมู่** กรอกชื่อแล้วบันทึก หมวดใหม่จะปรากฏในหน้าร้านและตัวเลือกหมวดสินค้า
2. กด **เพิ่มสินค้า / ไอดี** กรอกข้อมูลและราคาเป็นราคาต่อบัญชี
3. เลือกรูปจากเครื่อง: JPG, PNG หรือ WebP ไม่เกิน 5 MB ต่อรูป สูงสุด 8 รูป รูปแรกเป็นหน้าปก หรือใช้ลิงก์ HTTPS เดิมได้
4. สำหรับไอดีที่รายละเอียดและของเหมือนกัน เลือก **หลายบัญชีที่มีของเหมือนกัน (ไอดีไก่ตัน)** แล้วใส่ข้อมูลส่งมอบหนึ่งบัญชีต่อบรรทัด เช่น `ชื่อผู้ใช้:รหัสผ่าน` สูงสุด 100 บัญชีต่อครั้ง ถ้าข้อมูลบัญชีเดียวมีหลายบรรทัด ให้ปิดตัวเลือกนี้
5. กดบันทึก สินค้าชุดเดียวกันรวมเป็นหนึ่งการ์ดพร้อมจำนวนพร้อมขาย เมื่อมีบัญชีใหม่ กด **เติมสต็อก** จากการ์ดหรือหน้ารายละเอียดสินค้าได้ทันที ใช้รูปและรายละเอียดเดิม

แต่ละบัญชียังคงมี listing ID และข้อมูลส่งมอบเข้ารหัสแยกกัน การซื้อ/จองทำธุรกรรมผ่านระบบเดิม สินค้าที่จอง/ขายแล้วไม่นับเป็นพร้อมขาย ผู้ซื้อเห็นเฉพาะข้อมูลบัญชีที่ชำระครบ ระบบป้องกันข้อมูลส่งมอบซ้ำในชุดที่เติมและป้องกัน retry เพิ่มซ้ำด้วย idempotency key

รูปผ่านการ decode/re-encode เป็น WebP ย่อไม่เกิน 1920×1920 ลบ metadata และไม่รองรับ SVG/ภาพเคลื่อนไหว เก็บในตาราง `media` ของ SQLite บน NAS จึงอยู่ใน persistent volume และสำรองพร้อม DB ไม่ต้องใช้ผู้ให้บริการฝากรูป การนำรูปออกจากแบบฟอร์มไม่ลบไฟล์ที่อัปโหลดแล้ว (เพื่อไม่ให้รูปสินค้าที่ใช้อยู่เสีย)

Migration เพิ่มตาราง `categories`, `media` และคอลัมน์ `listings.group_id` โดยไม่แก้ข้อมูลส่งมอบหรือคำสั่งซื้อเดิม สินค้าเก่าที่ยังไม่มี group_id ใช้ id ของตัวเองเป็นกลุ่ม และสามารถเติมสต็อกได้

ทดสอบ backend 23 กรณี frontend 15 กรณี และทดสอบเลือกไฟล์/เพิ่มหมวด/เพิ่มสองบัญชี/เติมอีกบัญชีผ่าน UI ในฐานข้อมูลจำลองแยก ไม่เพิ่มสินค้าทดสอบในร้านจริง
