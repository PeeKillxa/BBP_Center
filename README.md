# BBP Center

เว็บหน้าร้านไอดีเกมและบริการฟาร์ม พร้อม Google/Discord OAuth, กระเป๋าเงิน TrueMoney, การซื้อ/จอง และหลังบ้านที่ตรวจสิทธิ์บน Node.js/SQLite

เริ่มใช้งานและตั้งบัญชีเจ้าของร้าน: [docs/LAUNCH.md](docs/LAUNCH.md)

ตั้งค่า Google/Discord: [docs/OAUTH_SETUP.md](docs/OAUTH_SETUP.md)

ไม่มีบัญชี ยอดเงิน สินค้า รีวิว หรือปุ่มสิทธิ์เจ้าของร้านที่สร้างไว้ล่วงหน้า ข้อมูลร้านและการเงินเก็บใน `server/data/` ซึ่งไม่อยู่ใน Git
